# 포켓몬 아레나

**플레이:** https://pokemon-arena-rosy.vercel.app · **저장소:** [songyh1996/pokemon-arena](https://github.com/songyh1996/pokemon-arena) (private)

Vercel Hobby의 정적 배포입니다. `main` 브랜치에 푸시하면 자동으로 다시 배포됩니다. 게임 URL은 공개 접근 가능하며, 저장소만 비공개입니다.

1·2세대 인기 포켓몬 **50마리와 게스트 캐릭터 유나**, 각 팀 **6마리**로 즐기는 실시간 팬 게임입니다. CPU전과 방 코드로 초대하는 친구 대전을 지원합니다. 한 번에 양쪽 한 마리씩 싸우며, **P**로 파트너를 교체합니다. Pokémon Battlegrounds의 *RED vs GOLD*에서 영감을 받았습니다.

## 실행

Node.js 20 이상. 외부 패키지 설치 없이 `npm start` 후 **http://localhost:5173** 에 접속합니다. 서버는 127.0.0.1에만 바인딩됩니다. 다른 포트는 `PORT=5174 npm start`.

## 친구와 대전

1. **친구와 대전** → 내 포켓몬 6마리 선택 → **1:1 / 2:2** 선택 → **방 만들기**.
2. **초대 링크 복사** 또는 6자리 코드를 친구에게 전달합니다. 친구도 6마리를 고르고 참가합니다.
3. 방장은 각 자리의 **팀 바꾸기**로 팀원을 배치합니다. 빈 자리의 드롭다운에서 **AI와 난이도**를 선택할 수 있습니다.
4. 전원이 **준비 완료**를 누르면 리소스를 불러온 뒤 함께 시작합니다. 사람 3명이면 빈 자리에 AI를 추가해 **사람 2명 vs 사람 1명 + AI**로 플레이할 수 있습니다.

- 한 방에 최대 4명, 동시에 최대 5개 방입니다. 사용자 10명 규모를 목표로 하며 10명 + AI 2명 / 3방 동시 연결을 검증합니다.
- 2:2는 각자 6마리 파티를 가진 네 트레이너가 한 무대에서 동시에 전투합니다. 아군 피해는 없고, 빔·범위 기술은 두 상대를 함께 타격할 수 있습니다.
- 자동으로 가까운 상대를 공격합니다. **상대 전환** 버튼 또는 **T** 키로 다른 상대를 지정합니다. 아군 상태와 두 상대의 상태를 HUD에서 확인합니다.
- 한 트레이너의 파티가 전멸해도 아군이 살아 있으면 계속됩니다. 두 트레이너의 파티가 모두 전멸하면 패배합니다. 결과와 MVP는 팀원 두 명의 기여도를 합산합니다.
- 교체 메뉴에서는 **모든 플레이어의 전투를 최대 15초** 정지합니다. 시간이 끝나면 수동 교체는 취소하고, 기절 상태라면 살아 있는 첫 포켓몬을 선택합니다.
- 메뉴 일시 정지는 **모든 플레이어 최대 60초**입니다. 어느 플레이어든 계속하기를 누를 수 있고, 모든 재개는 **3 → 2 → 1** 이후 시작합니다. 정지 중 체력·투사체·쿨타임·전투 시간은 멈춥니다.
- 타이머 옆 서버 왕복 핑을 매초 측정해 표시합니다. **≤80ms 초록 / 81–150ms 노랑 / >150ms 빨강**, 연결이 끊기면 재접속 상태를 표시합니다.
- 30초 안에 같은 탭에서 재접속하면 이어서 플레이합니다. 명시적으로 나가거나 재접속 시간이 끝나면 해당 트레이너의 파티가 기권합니다. 2:2에서 아군이 남아 있으면 전투는 계속됩니다. 대기는 15분 후 만료되고, 실제 전투 15분에 남은 체력 비율로 승패를 결정합니다.

### 서버와 비용

전용 Cloudflare Worker `pokemon-arena-multiplayer`와 SQLite Durable Objects `ArenaRoom`, `ArenaDirectory`를 사용합니다. 서버는 60Hz로 판정하고 약 20Hz로 상태를 전송합니다. 클라이언트는 이동·회피를 즉시 예측하고 상대 이동을 보간하며, HP와 명중 결과는 서버만 결정합니다. 재접속용 세션 정보는 탭의 sessionStorage에 저장합니다.

프런트엔드는 기존 Vercel, 서버는 **Workers Free**입니다. Jetstream의 Firebase·R2·Worker·DNS 설정을 연결하거나 수정하지 않습니다. Cloudflare 계정의 무료 한도는 공유합니다. [현재 공식 무료 한도](https://developers.cloudflare.com/durable-objects/platform/pricing/)는 DO 요청 100,000단위/일, 실행 13,000 GB-s/일, SQLite 쓰기 100,000행/일입니다. 초과 시 해당 작업이 제한되며 자동 유료 전환하지 않습니다. 사용 시간에 따라 한도에 도달할 수 있습니다.

10명이 모두 매일 2시간 연결해 전투할 때 입력 20회/초와 핑 1회/초는 약 75,600 요청 단위/일입니다(수신 WebSocket 메시지 20개당 1단위). 여기에 연결·방 관리·알람이 더해집니다. 유저 수만으로 무제한 무료를 보장하지 않습니다.

### 멀티플레이어 개발과 배포

```sh
npm ci
npm start                     # 터미널 1: localhost:5173
npm run dev:multiplayer        # 터미널 2: localhost:8787
npm test
npm run test:multiplayer       # 로컬 Worker 연결 통합 테스트
# 4명 및 3명+AI, 팀 변경/교체/재접속:
node scripts/test-multiplayer-teams.mjs http://127.0.0.1:8787
# 빈 테스트 서버에서 10명+AI 2명/3방 부하 확인:
node scripts/test-multiplayer-teams.mjs http://127.0.0.1:8787 --load
```

- `server/match.js`: 입력 검증, 방장/팀/AI 설정, 전원 정지/카운트다운, 재접속.
- `server/worker.js`: WebSocket, 전용 DO, 방 제한과 빈 방 정리.
- `src/net-state.js`, `src/multiplayer.js`: 상태 직렬화, 각 플레이어 시점, 예측·보정·핑.
- `wrangler.jsonc`: 포켓몬 전용 리소스만 선언합니다. 키나 Firebase/R2 바인딩은 없습니다.
- 서버: 공식 `wrangler login --scopes account:read user:read workers_scripts:write --use-keyring` 후 `npm run deploy:multiplayer`.
- 프런트엔드: `src/network-config.js`에 배포한 Worker URL을 지정하고 `npm run build`. Vercel에는 **dist/만** 올립니다.
- Worker를 수정할 때에는 기존 전투가 끝난 뒤 배포하세요. 재시작 시 최근 5초 체크포인트로 복구될 수 있습니다.

## 정적 빌드와 Vercel

- `npm run build`: 외부 빌드 의존성 없이 `dist/`에 게임을 생성합니다. `public/assets`는 배포 시 `/assets`에서 제공됩니다.
- `npm run preview`: 완성된 정적 빌드를 **http://localhost:5174** 에서 확인합니다.
- Vercel: Framework **Other**, Build Command **npm run build**, Output Directory **dist**. `vercel.json`에 설정되어 있으며 공유 미리보기용 Node.js Functions(`/api/invite`, `/api/og`)도 함께 배포합니다. 별도 환경 변수는 필요하지 않습니다.
- 자동 배포는 기존 **Vercel Git 연동**이 `main` push 시 처리합니다. 중복 배포를 만들지 않도록 유지합니다.
- `.github/workflows/deploy-vercel.yml`은 PR과 `main`에서 전체 테스트·정적 빌드·Worker 번들을 검증합니다. 기본 실행에는 배포 secret이 필요하지 않습니다.
- Actions의 수동 배포는 `main`에서 `deploy`를 명시적으로 켠 경우에만 실행됩니다. 이 대체 경로에는 `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID` secrets가 필요합니다. `.vercel/project.json`이나 토큰을 커밋하지 않습니다.
- GitHub 저장소는 공개입니다. `dist`, `node_modules`, `.vercel`, 환경 변수 파일과 개인 키는 Git에서 제외합니다.
- 공개 정적 파일은 `dist/`의 게임 코드와 에셋만 포함합니다. 초대 페이지와 이미지 함수의 서버 코드는 Vercel 함수로만 실행하며 정적 파일로 공개하지 않습니다. 저장소 관리 파일·테스트·인증 정보는 정적 배포에서 제외합니다.
- 검색 노출을 줄이기 위해 `robots.txt`와 `X-Robots-Tag: noindex, nofollow`를 제공합니다. **검색 차단은 배포 URL의 접근 제어가 아닙니다.** 비공개 접속이 필요하면 Vercel 배포 보호를 별도로 설정해야 합니다.

## 링크 공유

- 기본 링크는 1200×630 PNG 썸네일과 게임 설명을 제공합니다.
- 방 생성·참가 시 입력한 이름은 대기실과 배틀 HUD에 표시됩니다. 초대 링크 복사는 방장의 이름을 포함한 `/invite/CODE?name=...&lang=...` 주소를 만듭니다.
- 초대 페이지의 제목·설명은 서버에서 HTML에 넣고, `/api/og`는 이름·방 코드가 들어간 PNG를 생성합니다. 미리보기 요청은 방을 만들거나 접속 자리를 차지하지 않습니다. 기존 `/?room=CODE` 링크도 계속 열립니다.
- 공유 이미지와 글꼴은 로컬 에셋을 사용합니다. 기본 이미지 재생성은 `node scripts/generate-share-image.mjs`; 글꼴 출처·라이선스는 `assets/share/`에 있습니다.
- Google Analytics는 production 도메인에서만 실행하고 초대자의 이름·방 코드·개인화된 페이지 제목을 보내지 않습니다.

## 파티 편성

- 새로 열 때 내 파티는 항상 **0/6**입니다. 포켓몬 초상화를 누르면 다음 빈자리에 자동으로 추가됩니다. 슬롯을 먼저 고를 필요가 없습니다.
- 선택한 포켓몬이나 채워진 슬롯을 다시 누르면 제외됩니다. 다음 선택은 생긴 빈자리를 채웁니다. 같은 팀은 중복 불가이며 여섯 마리가 완성되어야 시작할 수 있습니다.
- 상대는 기본 **AUTO**입니다. 시작할 때 여섯 마리를 무작위로 편성합니다. 원하면 상대도 직접 고를 수 있습니다.
- 최근에 직접 고른 파티는 **최근 파티**를 눌렀을 때만 불러옵니다. 이전 자동 기본 파티는 복원하지 않습니다. 랜덤 채우기와 비우기도 명시적인 버튼으로 제공합니다.
- 포켓몬 선택 시 실제 울음소리가 재생됩니다. 검색과 타입 아이콘 필터, 여섯 개의 트레이너 기술 아이콘과 5단계 난이도를 제공합니다. 드롭다운으로 기술을 고르지 않습니다.
- 출전할 두 파티의 실제 스프라이트를 준비한 다음 배틀이 시작됩니다. 난이도·트레이너 기술·소리/효과 설정은 유지됩니다.

## 조작

- **모바일:** 왼쪽 큰 조이스틱을 드래그하여 360도 이동하고, 오른쪽 6개 기술 버튼을 누릅니다. 이동을 유지한 채 다른 손가락으로 기술·회피를 즉시 사용할 수 있습니다. 회피는 오른쪽 아래, 교체·메뉴는 왼쪽 위입니다. 세로·가로 화면과 안전 영역에 맞추며, 배틀 중 페이지는 스크롤되지 않습니다. 메뉴에서 조작법·설정에 접근할 수 있습니다.
- 터치 해제·취소·포커스 상실·화면 회전·메뉴 진입은 입력을 정리합니다. 카운트다운과 상대 자동 교체에서는 잡고 있는 이동 입력을 유지하고, 내 포켓몬 교체에서는 해제합니다.

- **방향키:** 이동. 대각선 속도를 정규화합니다.
- **평타:** 항상 자동. 사거리 안에 상대를 두면 이동 중에도 공격하며, 평타 준비가 이동을 느리게 하지 않습니다. A/Space/T나 공격 토글은 없습니다.
- **Q / W / E:** 현재 포켓몬의 고유 기술. 이동만 하는 순간이동은 없으며, 공격 돌진은 피해를 주는 기술입니다.
- **R:** 가장 강한 기술. 최초 30초 충전, 사용 후 60~70초 재사용 대기. 대기 포켓몬도 같은 전투 시간으로 충전됩니다.
- **S:** 선택한 트레이너 기술. 고정 점멸은 제거했습니다.
- **D:** 방향성 회피. 즉시 0.5초 무적, 2초 재사용, 175 거리/0.28초 이동. 경직 중에도 사용 가능하며 방향키가 없으면 상대 반대편으로 회피합니다. 적 유도탄과 발사 전 추적 공격의 조준을 끊습니다. 탄을 삭제하지 않으므로 이후 직선 궤도로 돌아가면 맞을 수 있습니다. 체력 회복이나 화상 정화는 하지 않습니다.
- **P:** 교체할 포켓몬 선택. 방향키/Enter 또는 클릭으로 결정, P/Esc로 취소합니다.
- **Esc:** 메뉴/재개. **M:** 소리. **H:** 현재 포켓몬 기술 설명.

물리 키 위치로 입력을 처리하므로 한글 IME 상태에서도 QWER/S/D/P를 사용할 수 있습니다. 키보드와 클릭, 터치 이동 패드를 지원합니다. 혼자 할 때는 다른 탭으로 이동하면 전투가 자동 정지됩니다. 친구 대전에서는 메뉴로 일시 정지를 요청해야 하며, 탭 이동만으로 상대 전투를 멈추지는 않습니다.

## 트레이너 기술

- **가속 / Ghost:** 4초 동안 이동 속도 +50%. 재사용 18초.
- **위압 / Exhaust:** 사거리 450, 3초 둔화와 주는 피해 35% 감소. 재사용 20초.
- **배리어 / Barrier:** 최대 HP 20% 보호막, 3초 지속. 재사용 22초.
- **회복 / Heal:** 현재 포켓몬의 최대 HP 16% 회복. 초과 회복/부활 없음. 재사용 26초.
- **정화 / Cleanse:** 경직·둔화·화상·위압·점화 제거 및 3초 상태 이상 방어. 피해 자체를 막는 무적은 아닙니다. 재사용 16초.
- **점화 / Ignite:** 사거리 430, 4초 동안 총 144의 지속 피해. 회피/보호막으로 피해를 줄일 수 있습니다. 재사용 20초.

S와 D 재사용 시간은 팀 전체가 공유합니다. 포켓몬 교체로 재사용 시간을 초기화할 수 없습니다. 트레이너 기술은 MP를 쓰지 않습니다.

선택한 트레이너 기술의 설명은 기본으로 표시됩니다. 상대 설정에서 **랜덤**을 고르면 CPU가 배틀 시작마다 6개 기술 중 하나를 선택합니다. 같은 팀 재대결도 기술은 다시 추첨하며, 내 기술과 친구의 선택에는 영향을 주지 않습니다.

MP는 최대 100이며 전투 시간 기준 초당 **3**씩 회복합니다. 출전·대기 포켓몬과 플레이어·CPU·온라인 양쪽에 동일하게 적용하며, 일시 정지와 교체 선택·카운트다운 중에는 회복하지 않습니다. 기본 공격·회피·트레이너 기술은 MP를 사용하지 않아, MP를 모으는 동안에도 전투를 이어갈 수 있습니다.

## 난이도

난이도는 **입문 → 쉬움 → 도전 → 챔피언 → 마스터**의 5단계입니다. 선택값은 파티와 함께 브라우저에 저장되며, 기존 저장과 회귀 테스트를 위해 `standard`(도전)와 `expert`(챔피언) ID 및 수치는 그대로 유지합니다. 차이는 주로 공격 예고와 후딜, 탄속·유도·이동 예측, 일반 기술 사용 주기에서 나며 피해 배율은 0.90~1.18로 제한합니다.

마스터는 별도의 전술 AI를 사용합니다. 0.18초 늦게 관측한 이동에서 회전·탈출 경로를 예측하며, 보이는 위협을 최소 0.20초 관찰한 뒤 실제 D 회피나 보호막으로 대응합니다. 위험 장판을 피하고, 관측한 플레이어 회피 이후 압박 거리를 좁히며, 사거리·MP에 맞는 기술을 선택합니다. 확정된 공격이나 후딜을 취소해 회피하지 않으며 플레이어 입력·숨은 쿨타임을 읽지 않습니다. HP·피해 배율·플레이어 회피 성능·궁극기 충전은 그대로입니다. 나머지 네 단계의 AI와 수치도 유지합니다.

MP가 절반 미만이면 준비된 기본 공격을 우선 활용하고, 관측한 상대의 회피 중에는 즉시 공격에 남은 MP를 낭비하지 않습니다. 자원 조정 후 난이도 검증은 원거리·근거리 4종과 원형 이동·거리 벌리기 각각 4개 시작 위상을 비교합니다.

도전의 장판/궁극기 공격 예고는 각각 0.95초/1.10초로 0.9초 이상을 유지합니다. 수비형 기술의 짧은 0.2초 상태 표시는 모든 난이도에서 동일합니다.

## 교체와 기절

- 양쪽에 한 마리만 출전합니다. 여섯 마리가 동시에 싸우지 않습니다.
- 수동 교체에는 8초 재사용 시간이 있으며, 메뉴를 선택하는 동안 전투가 멈춥니다.
- 각 포켓몬의 HP, MP, QWER 쿨타임을 유지합니다. 대기 중에도 기술 쿨타임/상태 지속 시간이 감소하고 MP가 회복되지만, 대기 포켓몬에게 화면 밖 지속 피해를 주지는 않습니다.
- 교체 위치는 유지되며 새 체격에 맞춰 경계를 보정합니다. 출전 직후 0.6초 보호를 제공합니다.
- 물러난 포켓몬의 준비 중 공격과 투사체/장판은 취소됩니다. **상대가 발사한 공격은 지우지 않습니다.**
- 내 포켓몬이 기절하면 살아 있는 대기 포켓몬을 반드시 선택합니다. 이 선택은 취소할 수 없고 수동 교체 쿨타임에 막히지 않습니다.
- 상대는 기절 후 다음 살아 있는 포켓몬을 약 1초 뒤 내보냅니다. 한 팀의 여섯 마리가 모두 기절해야 승패가 결정됩니다.

## 게스트 캐릭터 유나

**유나 (Yuna)**는 사용자 사진을 바탕으로 만든 오리지널 샴고양이입니다. 노말 타입의 근접 캐릭터이며 포켓몬 도감 번호나 기존 포켓몬 울음소리를 사용하지 않습니다. 파티 선택에서 유나 또는 Yuna를 검색할 수 있습니다.

유나의 초상화와 8방향 스프라이트는 제공된 사진을 참고해 OpenAI 이미지 생성으로 제작했습니다. 원본 사진은 저장소에 포함하지 않습니다. 아트 출처는 `public/assets/pokemon/yuna/animations.json` 및 `sprite/credits.txt`, `portrait/credits.txt`에 기록되어 있습니다. PMD SpriteCollab 원본으로 표기하지 않습니다.

## 전투와 화면

- 적은 예고 → 공격/투사체 이동 → 후딜 순서로 행동하며, 한 행동 중 다른 공격을 겹치지 않습니다.
- 고정 조준선, 범위 예고, 초록색 반격 기회, D 유도 해제와 실제 회피 피드백을 표시합니다.
- 5단계 난도가 올라가면 공격 예고와 후딜이 짧아지고 탄속·유도·예측·기술 연계가 강해집니다. 피해량 변화는 보조적인 수준으로 제한합니다.
- 포켓몬 RPG풍 도감, 여섯 슬롯의 파티, HP 바와 몬스터볼 잔여 표시, 기술 메뉴, 교체/기절/승패 화면을 사용합니다.
- 실제 방향별 PMD 스프라이트, 타격 시점에 맞춘 애니메이션, 반동/히트스톱, HGSS 챔피언 음악을 유지했습니다.
- 원본에 Faint가 없는 34종은 매니페스트에 명시한 실제 Hurt 애니메이션을 대체 사용합니다. 토게피의 Shoot는 실제 Attack 시트로 대체합니다. 원본에 없는 그림을 생성한 것은 아닙니다.

## 타격감과 소리

- 기술의 속성과 형태에 맞춘 준비·발사·명중 소리가 각각 재생됩니다. 기본 공격, 회피, 회피 성공, 여섯 트레이너 기술, 궁극기, 교체에도 별도 피드백을 사용합니다.
- 불꽃·물·전기·얼음·에스퍼·물리 공격 등의 궤적과 명중 이펙트를 구분하며, 방향성 카메라 흔들림과 반동을 적용합니다. 주황색 공격 예고와 초록색 반격 표시는 이펙트 위에 유지합니다.
- 음악과 효과음 볼륨은 독립적으로 조절됩니다. 캐릭터 선택 시 실제 포켓몬 울음소리를 사용하고, 반복 선택 시 이전 소리를 짧게 감쇠합니다.
- 화면 흔들림은 조절 가능하며 시스템의 모션 줄이기를 존중합니다. 하드웨어 진동은 브라우저 진동 API 또는 연결된 게임패드가 지원할 때만 동작합니다. 일반 데스크톱에 진동 장치를 만들어 주지는 않습니다.
- 효과·입자 개수와 진동 패턴은 제한됩니다. 테스트가 보장하는 것은 이벤트/안전 처리이며, 실제 기기의 진동 여부는 하드웨어에 따라 다릅니다.

# Share card font

Noto Sans KR, licensed under the SIL Open Font License (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanskr

NotoSansKR.ttf is a static weight-700 instance of NotoSansKR[wght].ttf,
created with fontTools.varLib.instancer.instantiateVariableFont(font, {'wght': 700}).
The static instance avoids variable-font parsing incompatibilities in the image renderer.
All fonts and artwork load locally; rendering cards requires no remote font request.

Regenerate the default PNG with `node scripts/generate-share-image.mjs`.
